# 雪线以下

《雪线以下：白岭连续失踪事件调查档案》是一款纯前端、单人、中文恐怖推理解谜游戏。

玩家通过调查工作台阅读档案、检查照片、检索旧网页、组合证据，并在暴雪封路前完成三次最终调查。游戏包含完整谜题链、10 条核心证据、3 份可实际收集的隐藏档案，以及由真相层级和行动后果共同构成的分层结局。

## 游玩

直接打开 `index.html`，或访问 GitHub Pages。建议使用最新版 Chrome、Edge、Firefox 或 Safari。

## 特性

- 纯 HTML / CSS / JavaScript，无后端、无构建步骤
- 浏览器 `localStorage` 自动存档
- 2000、2001、2003、2004、2005 五案串联
- 无可见热点的照片调查、自由关键词检索、证据组合、跨案件时间线
- CASE 05 与天气状态随调查进度逐步恶化
- 核心证据决定真相层级，最终行动决定事件后果
- 分层提示与响应式移动端界面
- 4 个真相层级，三次最终行动各自追加独立后果

## 本地运行

任何静态服务器均可，例如：

```bash
npx serve .
```

也可直接双击 `index.html` 游玩。

## 美术

主视觉、2000 班级照、2001 营地照、2003 纪录片底片和 1976 气象站合影由 OpenAI ImageGen 为本项目生成；其余界面由 HTML/CSS 绘制。
