# 雪线以下

《雪线以下：白岭连续失踪事件调查档案》是一款纯前端、单人、中文恐怖推理解谜游戏。

玩家通过调查工作台阅读档案、检查照片、检索旧网页、组合证据，并在暴雪封路前完成两项最终调查与一项资料处置。游戏包含完整谜题链、10 条核心证据、3 份可实际收集的异常档案，以及由真相层级和行动后果共同构成的分层结局。

## 游玩

直接打开 `index.html`，或访问 GitHub Pages。建议使用最新版 Chrome、Edge、Firefox 或 Safari。

## 特性

- 纯 HTML / CSS / JavaScript，无后端、无构建步骤
- 浏览器 `localStorage` 自动存档
- 通关元进度独立保存；标题页提供 4 槽结局档案与公开/保护/封存三项处置记录，“重新开始”会保留记录，“清除全部记录”才会永久删除
- 2000、2001、2003、2004、2005 五案串联
- 无可见热点的照片调查、受档案发现链约束的关键词检索、证据组合、跨案件时间线
- CASE 05 与天气状态随调查进度逐步恶化
- 核心证据决定真相层级，最终行动决定事件后果
- 分层提示与响应式移动端界面
- CASE 05 出现后可主动进入不可回头的最后15分钟
- 4 个可正常抵达的真相层级，2项最终调查与1项处置分别影响信息和后果

## 本地运行

任何静态服务器均可，例如：

```bash
npx serve .
```

也可直接双击 `index.html` 游玩。

## 流程测试

`smoke.cjs` 默认测试本地文件，并优先使用 Playwright 自带 Chromium；可通过 `BROWSER_PATH` 指定浏览器，通过 `LIVE_URL` 对部署后的网页执行同一套流程。

```bash
node smoke.cjs
LIVE_URL=https://sakawa060209.github.io/snowline-below/ node smoke.cjs
```
